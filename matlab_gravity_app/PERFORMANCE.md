# 渲染性能与显示质量

本次优化针对密集透明曲面、冗余国界线，以及参数变化时整幅图重建造成的停顿。修改只作用于显示层；`gravity_at_location.m`、EGM2008 系数和原始 1° 网格保持不变。

## 实测结果

2026-09-27，在 MATLAB R2022b Update 10、RTX 4070 Laptop GPU 硬件 OpenGL 上，用可见的 1510×880 窗口测量。下表为含 `drawnow` 的操作耗时中位数，越小越好：

| 操作 | 原版 b8fdcb8 | 均衡（默认） | 流畅 | 精细 |
|---|---:|---:|---:|---:|
| 调不透明度 | 530 ms | 79 ms | 43 ms | 223 ms |
| 调径向夸张 | 529 ms | 82 ms | 51 ms | 200 ms |
| 切换总重力/扰动 | 510 ms | 98 ms | 67 ms | 183 ms |
| 返回已访问球面 | 575 ms | 19 ms | 21 ms | 22 ms |
| 返回已访问 Miller | 611 ms | 54 ms | 19 ms | 135 ms |

自动相机旋转重绘吞吐量分别为 **7.64、15.24、29.50、8.90 次/秒**。这不是保证的鼠标交互 FPS。均衡档调透明度约快 6.7 倍；流畅档自动重绘吞吐量约为原版的 3.86 倍。

| 几何数据 | 原版 | 均衡 | 流畅 | 精细 |
|---|---:|---:|---:|---:|
| 重力表面顶点 | 65,341 | 16,833 | 4,368 | 65,341 |
| 单条国界路径顶点 | 101,875 | 29,484 | 22,585 | 101,875 |
| 首都点 | 197 | 197 | 197 | 197 |

应用窗口热启动仍约 2.2–2.6 秒（不含 MATLAB 进程启动）；本次收益主要在交互重绘。三档的默认模型结果与原版完全一致：`g=9.801478885851168 m/s²`、`G=686.1035220095818 N`。

完整采样与环境信息：[原版 JSON](docs/benchmarks/baseline.json)、[优化版 JSON](docs/benchmarks/optimized.json)。性能随显卡、窗口大小及机器负载变化，精细档保留更多几何数据，因此旋转收益小于流畅档。

## 已实施的优化

1. **保留图形对象**：每个视图只在首次访问时创建对象。之后更新数据或样式，切回视图复用对象，并保留相机方向、缩放。
2. **按需缓存**：对显示量和质量档位缓存网格、等值线、插值位置和球面方向向量。透明度变化不重算几何，径向夸张变化不重跑等值线或国界插值。
3. **显示细节分档**：流畅约 4°、均衡约 2°、精细原始 1°。源网格不覆盖；色标范围及径向归一化仍由完整源场确定。
4. **简化国界**：使用有容差的折线简化，并限制长线段长度，使线条仍贴合曲面。保留每个独立片段、小岛、闭合环端点和经度接缝；全部 197 个首都继续绘制。
5. **流畅档免透明排序**：使用单层不透明曲面，将 `jet` 颜色按不透明度预合成到原灰色基底，并隐藏重复底层及白色描边。其视觉不透明度可调，但不执行真实的透明面排序；均衡、精细保留真实半透明。

## 使用

```matlab
gravity_field_app('RenderQuality','fast')      % 旋转优先
gravity_field_app('RenderQuality','balanced')  % 默认
gravity_field_app('RenderQuality','fine')      % 完整显示细节
```

也可直接使用界面中的“显示质量”下拉框。已打开的旧版窗口仍绑定旧回调，需要关闭旧窗口后重新运行更新的函数。

## 基准方法

`tools/benchmark_rendering.m` 在同一机器、同样窗口大小下，对旧版提交 `b8fdcb8` 和当前版本测量。先预热，再取三次启动和五次控件操作的中位数。控件耗时包含回调与完整 `drawnow`，自动旋转测量 24 次相机变化及绘制提交。

自动旋转指标是脚本绘制吞吐量，不是人工拖动的实测 FPS，也不保证所有机器达到同样速度。首次构建某个视图或显示组合仍会有一次数据准备开销；缓存主要改善后续操作。

```matlab
addpath('tools')
report = benchmark_rendering; % 旧版和当前三档依次测量
```

旧版复现需要通过 Git 克隆并保留提交历史；ZIP 下载的项目可用 `benchmark_rendering('Target','optimized')` 只测当前版本。测量时避免同时运行其他 MATLAB 图形测试。结果写入本地 `artifacts/rendering_*_benchmark.json`。
